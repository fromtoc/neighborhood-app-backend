1. 通用

回應格式

// 成功
{ "code": 200, "message": "成功", "data": { ... }, "traceId": "abc-123" }

// 失敗
{ "code": 400, "message": "暱稱不得為空", "data": null, "traceId": "abc-456" }

錯誤碼

code說明
200成功
400參數錯誤 / 業務邏輯錯誤
401未登入 / Token 過期
403權限不足（如訪客嘗試發文）
404資源不存在
422欄位驗證失敗
429請求過於頻繁（限流）
500伺服器錯誤

認證方式

需要認證的 API，在 Header 加上：

Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...

收到 code: 401 時，用 Refresh Token 呼叫 POST /api/v1/auth/refresh 換新 Access Token。

JWT Claims 包含：userId、role (GUEST/USER/ADMIN/SUPER_ADMIN)、defaultNeighborhoodId、jti

角色權限

角色可執行操作
GUEST瀏覽所有內容（不可發文、留言、按讚、收藏、聊天、關注里）
USER所有一般功能（發文、留言、按讚、收藏、聊天、關注里）
ADMINUSER 權限 + 發布資訊/廣播、管理店家、查看後台
SUPER_ADMINADMIN 權限 + 管理其他管理員

🔐 2. 登入 / 註冊

POST /api/v1/auth/guest 公開

訪客快速登入（無需第三方帳號）

Request Body

欄位型別必填說明
neighborhoodIdLong必填預設里 ID
deviceIdString選填裝置識別碼（限流用）

Response — data

{
  "accessToken": "eyJ...",
  "refreshToken": "abc...",
  "accessExpiresIn": 900,
  "user": {
    "id": 42,
    "isGuest": true,
    "nickname": null,
    "defaultNeighborhoodId": 123
  }
}
POST /api/v1/auth/firebase 公開

第三方登入（Google / Apple / Facebook / Phone / LINE custom token）

Request Body

欄位型別必填說明
idTokenString必填Firebase ID Token
neighborhoodIdLong必填預設里 ID
deviceIdString選填裝置識別碼

Response

同上 AuthResponse，isGuest 為 false

POST /api/v1/auth/line/custom-token 公開

LINE Login — 用 OAuth code 換 Firebase custom token

Request Body

欄位型別必填說明
codeString必填LINE OAuth authorization code
redirectUriString必填LINE 回呼 URI
codeVerifierString必填PKCE code verifier
deviceIdString選填裝置識別碼

Response — data

{ "firebaseCustomToken": "eyJ..." }
取得 custom token 後，用 Firebase SDK signInWithCustomToken() 登入，再取得 idToken 呼叫 /auth/firebase。
POST /api/v1/auth/line/id-token 公開

LINE Login — 直接用 LINE ID Token 換 Firebase custom token

Request Body

欄位型別必填說明
idTokenString必填LINE ID Token
nonceString選填LINE nonce
deviceIdString選填裝置識別碼

Response — data

{ "firebaseCustomToken": "eyJ..." }
POST /api/v1/auth/refresh 公開

用 Refresh Token 換新 Access Token

Request Body

欄位型別必填說明
refreshTokenString必填Refresh Token

Response

同 AuthResponse

POST /api/v1/auth/logout 需登入

登出（將 Access Token 加入黑名單）

Request Body

欄位型別必填說明
refreshTokenString選填一併作廢 Refresh Token

📍 5. 里頁面（五大 Tab）

里頁面是 App 的核心，包含五個 Tab：首頁、資訊、社群、店家、聊聊。

進入里頁面後，先呼叫以下 API 取得里的基本資訊：

GET /api/v1/geo/li?city=台北市&district=大安區&li=龍泉里

取得 id 後，後續 API 都用這個 neighborhoodId。

📢 6. 資訊 Tab

資訊 Tab 分為兩區：區資訊（scope=district）和 里資訊（scope=li）。

每區有四種類型：貼文、廣播(一般)、廣播(中等)、廣播(緊急)

📍 13. 關注里管理

GET /api/v1/follows 需登入（非訪客）

取得關注里清單 + 冷卻資訊

Response — data

{
  "follows": [
    { "id": 123, "name": "龍泉里", "city": "台北市", "district": "大安區", "isDefault": true, "alias": "老家" },
    { "id": 456, "name": "樂善里", "city": "桃園市", "district": "龜山區", "isDefault": false, "alias": "公司" }
  ],
  "cooldownSlots": 0,
  "cooldownExpiredAt": null
}
最多關注 3 個里。取消關注後有 7 天冷卻期。cooldownSlots = 冷卻中的 slot 數，cooldownExpiredAt = 最近一個冷卻的到期時間。
POST /api/v1/follows/{neighborhoodId} 需登入（非訪客）

關注一個里

⚡ 20. WebSocket 即時通訊

聊天使用 STOMP over WebSocket 進行即時通訊。

連線

WebSocket URL: wss://your-domain.com/ws?token={accessToken}

// STOMP 連線
const client = Stomp.over(new SockJS('/ws?token=eyJ...'));
client.connect({}, onConnected, onError);

訂閱聊天室

// 訂閱特定聊天室的即時訊息
client.subscribe('/topic/rooms/{roomId}', (message) => {
  const msg = JSON.parse(message.body);
  // msg = ChatMessageResponse
});

發送訊息

// 透過 STOMP 發送（推薦，比 REST 更即時）
client.send('/app/chat.send/{roomId}', {},
  JSON.stringify({ content: '你好！' })
);

收到的訊息格式 (ChatMessageResponse)

{
  "id": 501,
  "roomId": 10,
  "userId": 42,
  "nickname": "小明",
  "content": "你好！",
  "type": "text",
  "createdAt": "2026-03-12T14:35:00"
}
WebSocket 連線斷開時，需要重連機制。建議使用指數退避重試（1s → 2s → 4s → 8s → max 30s）。
