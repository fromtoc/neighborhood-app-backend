1. 認證 & 登入

1.1 訪客登入

POST /auth/guest 公開

// Request
{ "neighborhoodId": 7742, "deviceId": "uuid" }

// Response
{
  "accessToken": "eyJ...",
  "refreshToken": "eyJ...",
  "accessExpiresIn": 86400,
  "user": {
    "id": 46, "isGuest": true,
    "nickname": null, "role": "GUEST",
    "defaultNeighborhoodId": 7742,
    "chiefNeighborhoodId": null
  }
}

1.2 Firebase 登入（Google / Apple / Facebook / Phone）

POST /auth/firebase 公開

{ "idToken": "Firebase ID Token", "neighborhoodId": 7742, "deviceId": "uuid" }

Response 同上，role 可能是 USER / LI_CHIEF / ADMIN / SUPER_ADMIN

1.3 LINE 登入

POST /auth/line/custom-token 公開

{ "code": "LINE auth code", "redirectUri": "...", "codeVerifier": "..." }
// Response: { customToken: "...", isNewUser: true }
// 用 customToken 呼叫 Firebase signInWithCustomToken，再用 Firebase idToken 呼叫 /auth/firebase

1.4 刷新 Token

POST /auth/refresh 公開

{ "refreshToken": "eyJ..." }

1.5 登出

POST /auth/logout 公開

{ "refreshToken": "eyJ..." } // optional
JWT Claims：sub=userId, role=角色, ngb=defaultNeighborhoodId, cnb=chiefNeighborhoodId (里長才有), type=ACCESS|REFRESH
Rate Limit：guest + firebase 登入有 10 req/60s 限制

7. @ Mention（標記）

GET /users/mention-candidates?keyword=張&neighborhoodId=7742&scope=li 需登入

Response

[
  { "id": 13, "nickname": "張里長", "avatarUrl": null, "badge": "堵南里里長" }
]

完整流程

  1. 搜尋：用戶輸入 @ 後呼叫 API（keyword 可為空，返回關注該里/區的用戶）
  2. scope 判斷：區級頁面傳 district，里級頁面傳 li
  3. 輸入框：選擇後顯示 @張里長（好看），內部記錄 nickname→userId 映射
  4. 提交前：把 @張里長 替換為 @[張里長](13) 格式存到後端
  5. 顯示時：正則解析 /@\[([^\]]+)\]\((\d+)\)/g，渲染為藍色可點擊連結 → /users/{userId}
  6. 純文字場景（通知預覽等）：text.replace(/@\[([^\]]+)\]\(\d+\)/g, '@$1')
  7. 中文輸入法：監聽 compositionstart / compositionend，組字中不攔截 Enter

17. 刪除 & 編輯規則

貼文刪除

  • 後端 status=2，原始資料保留，API 回傳時所有內容欄位為 null
  • contentDeleted=true：不可喜歡/留言/收藏/分享/編輯/刪除
  • 喜歡數和留言數仍顯示（只讀），有留言可展開查看
  • 0 留言 + 0 喜歡也要顯示（灰色不可點）

留言刪除

  • 後端 content_deleted=1，原始資料保留，API 回傳 content 為 null
  • contentDeleted=true：同貼文規則
  • 已刪除留言的子回覆仍保留可查看

編輯

  • 貼文編輯：只有本人，自動設 edited=1
  • 留言編輯：只有本人，自動設 edited=1
  • edited=true 時顯示「已編輯」標記

刪除權限

  • 本人可刪除自己的貼文/留言
  • ADMIN 可刪除非管理員的貼文/留言
  • SUPER_ADMIN 可刪除所有人的貼文/留言
