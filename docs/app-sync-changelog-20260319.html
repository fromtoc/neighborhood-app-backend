3. 新增功能：@ Mention（標記）新增

3.1 搜尋候選人 API

GET /api/v1/users/mention-candidates?keyword=張&neighborhoodId=7742&scope=li
// scope: "li" | "district"

// Response:
[{ "id": 13, "nickname": "張里長", "avatarUrl": null, "badge": "堵南里里長" }]

3.2 存儲格式

  • 輸入框：顯示 @張里長
  • 提交時：替換為 @[張里長](13) 格式送到後端
  • 顯示時：正則 /@\[([^\]]+)\]\((\d+)\)/g 解析，渲染為藍色可點擊連結 → /users/{userId}
  • 純文字場景（通知等）：text.replace(/@\[([^\]]+)\]\(\d+\)/g, '@$1')

3.3 scope 判斷

頁面scope
區資訊 / 區社群 / 區聊聊district
里資訊 / 里社群 / 里聊聊li
中文輸入法：需監聽 compositionstart / compositionend，組字中不攔截 Enter。

8. 變更：聊天未讀/已讀邏輯 變更

8.1 自動標記已讀時機

場景API 呼叫
進入任何聊天室PUT /chat/rooms/{roomId}/read
聊天中收到 WebSocket 新消息PUT /chat/rooms/{roomId}/read
離開聊天室返回列表PUT /chat/rooms/{roomId}/read
關閉私聊彈窗PUT /chat/rooms/{roomId}/read

8.2 聊天 tab badge

App 需在聊聊 tab 上顯示總未讀數 = 區聊天 + 里聊天 + 所有私聊的 unread count 總和。

計算方式：呼叫 GET /chat/unread-counts?roomIds=...，加總所有值。

8.3 WebSocket 即時刷新

訂閱 /topic/user/{userId}，收到 type: "chat" 或 type: "private_message" 時刷新未讀數。

11. 變更：私聊訊息分頁載入 變更

私聊不再一次載入全部，改為 cursor-based 分頁：

  • 初始載入：GET /chat/rooms/{roomId}/messages?limit=20
  • 往上滑加載更多：GET /chat/rooms/{roomId}/messages?limit=20&before={oldestMsgId}
  • 載入完畢判斷：回傳筆數 < limit 表示沒有更多
