GoLocal App 對接同步 commit: acb05b2 — 聊聊未讀/通知完整修正 + 即時刷新

1. 聊聊通知 refType 變更 Breaking

群聊通知的 refType 改為區分里/區：

場景舊 refType新 refType
里聊天chat_messagechat_li
區聊天—（之前不發通知）chat_district

App 導頁邏輯需更新：

  • refType === "chat_li" → 進入里聊天室
  • refType === "chat_district" → 進入區聊天室
  • refType === "user" → 私訊對話（不變）

2. 聊聊通知標題區分里/區 變更

之前統一「XX 在聊聊發了訊息」，現在改為：

  • 里聊天：「張里長 在堵南里聊聊發了訊息」
  • 區聊天：「張里長 在七堵區聊聊發了訊息」

3. 群聊通知合併 變更

  • 同一聊天室（同 refType）的未讀通知只保留一則
  • 新消息會更新 title、body、createdAt
  • 里聊天和區聊天分別合併（不會混在一起）
  • 後端同一用戶只推送一次 WebSocket / FCM（去重）

4. 區聊天新增通知 新增

之前區聊天室發消息不會觸發通知，現在會通知該區所有里的關注用戶。

5. 通知設定新增 mention 欄位 新增

DB Migration V43

ALTER TABLE user_notification_settings
    ADD COLUMN mention TINYINT(1) NOT NULL DEFAULT 1;

GET / PUT /notifications/settings

{
  // ...existing fields...
  "chat": 1,             // 聊聊新訊息
  "mention": 1,          // 被 @ 提及（新增）
  "privateMessage": 1    // 私訊
}

通知設定頁面的「聊天訊息」區塊應有三項：

設定欄位說明
💬 聊聊新訊息chat里/區聊天室有新訊息
＠ 被 @ 提及mention貼文、留言或聊天中被 @ 你
✉️ 私訊通知privateMessage收到私人訊息

6. /users/me Response 改為 record DTO 變更

之前回傳 Map<String, Object>（Swagger 無法顯示結構），現在改為 record：

{
  "nickname": "超管",
  "bio": "自我介紹",
  "useAvatar": true,
  "avatarUrl": "https://...",
  "role": "SUPER_ADMIN",      // 新增
  "badge": null,              // 新增（里長才有值）
  "postCount": 14,
  "bookmarkCount": 6,
  "followerCount": 0,
  "followingCount": 0
}

PUT /users/me/profile 的 Request Body 也改為 record：

{ "nickname": "新暱稱", "bio": "新介紹", "useAvatar": true }

7. 聊天已讀邏輯統一 變更

App 需在以下時機呼叫 PUT /chat/rooms/{roomId}/read：

時機說明
進入聊天室mount 時立即呼叫
收到 WebSocket 新消息正在看的聊天室收到消息時自動呼叫
離開聊天室返回列表或關閉彈窗時呼叫

標記已讀後，應刷新聊聊 tab 的未讀 badge（重新呼叫 GET /chat/unread-counts）。

8. 聊聊 tab 未讀 badge 變更

聊聊 tab 需顯示總未讀數 = 區聊天 + 里聊天 + 所有私聊的 unread count。

刷新時機：

  • App 啟動時
  • WebSocket 收到 type: "chat" 或 "private_message" 通知時
  • 進入/離開聊天室時
  • 定期輪詢（建議 30 秒）

9. RSS 新聞 urgency 改 null 變更

RSS 新聞爬蟲的貼文 urgency 從 "normal" 改為 null（貼文類型，不是廣播）。App 顯示時不需要顯示緊急程度標籤。
