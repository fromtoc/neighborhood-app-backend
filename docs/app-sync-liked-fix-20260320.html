GoLocal App 對接 — liked/bookmarked null 修正 commit: 57dd650 — 2026-03-20

1. PostResponse — liked / bookmarked 不再回傳 null 變更

之前

{
  "liked": null,       // 未登入或未查詢時為 null
  "bookmarked": null  // 未登入或未查詢時為 null
}

現在

{
  "liked": false,      // 預設 false，登入且有按讚時為 true
  "bookmarked": false // 預設 false，登入且有收藏時為 true
}
App 端不再需要做 null 判斷，liked 和 bookmarked 保證為 true 或 false。

影響的 API

API欄位
GET /posts?neighborhoodId=...liked, bookmarked
GET /posts/{id}liked, bookmarked
GET /posts/mineliked, bookmarked
GET /bookmarksliked, bookmarked
GET /users/{id}/postsliked, bookmarked

2. PostCommentResponse — liked 不再回傳 null 變更

之前

{
  "liked": null  // thread API 和 getComment 一律 null
}

現在

{
  "liked": false  // 預設 false，登入且有按讚時為 true
}

影響的 API

API說明
GET /posts/{postId}/comments留言列表（帶 token 回傳實際 liked 狀態）
GET /posts/{postId}/comments/{commentId}單則留言（預設 false）
GET /posts/{postId}/comments/{commentId}/thread本次修正重點：現在帶 token 會回傳每則留言的實際 liked 狀態

3. /thread API 新增 liked 支援 變更

GET /posts/{postId}/comments/{commentId}/thread

之前

所有留言的 liked 一律為 null，不管有沒有帶 token。

現在

帶 Authorization: Bearer {token} 時，chain 和 repliesByParent 裡每則留言的 liked 會回傳實際狀態（true 或 false）。未帶 token 時預設 false。

// Response 結構不變，liked 值變了
{
  "chain": [
    {
      "id": 45,
      "content": "留言內容",
      "liked": true,        // ← 之前是 null
      "likeCount": 3,
      "replyCount": 1
    }
  ],
  "repliesByParent": {
    "45": [
      {
        "id": 46,
        "liked": false,     // ← 之前是 null
        "likeCount": 0
      }
    ]
  }
}

App 端需調整

  • 移除 null 判斷：liked 和 bookmarked 保證為 Boolean，不再需要 liked ?? false 或 liked != null && liked
  • /thread API：帶 token 呼叫即可取得正確的 liked 狀態，用於討論串中每個留言的「已按讚」顯示
