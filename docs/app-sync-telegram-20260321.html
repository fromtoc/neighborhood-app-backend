GoLocal App 對接 — Telegram 通知 Log 接口 2026-03-21

新增 Telegram 通知機制，App 端可以透過 API 將 log、錯誤、關鍵事件發送到 Telegram 群組，方便即時監控。

1. 發送 Log 到 Telegram 新增

POST /api/v1/telegram/log
Authorization: Bearer {token}
Content-Type: application/json

Request Body

欄位型別必填說明
tagString否標籤，預設 "App"。例如 "Crash"、"Login"、"Payment"
messageString是訊息內容，空白時不發送
levelString否預設 "info"。設為 "error" 或 "alert" 會用告警格式

level 說明

levelTelegram 顯示格式用途
info📢 [tag] + 訊息 + 時間一般通知、操作紀錄
error / alert🚨 [tag] + 訊息 + 時間錯誤、異常、需要關注的事件

範例 1 — 一般 Log

POST /api/v1/telegram/log

{
  "tag": "Login",
  "message": "用戶透過 Google 登入成功",
  "level": "info"
}

Telegram 群組收到：

📢 [Login]
用戶透過 Google 登入成功
👤 User#5
03-21 12:05:30

範例 2 — 錯誤告警

POST /api/v1/telegram/log

{
  "tag": "Crash",
  "message": "NullPointerException at HomeFragment.onResume()\ndevice: Pixel 7, Android 14",
  "level": "error"
}

Telegram 群組收到：

🚨 [Crash]
NullPointerException at HomeFragment.onResume()
device: Pixel 7, Android 14
👤 User#5
03-21 12:05:30

Response

{
  "code": 200,
  "message": "success",
  "data": null
}

2. App 端使用建議

2.1 建議發送的事件

taglevel時機
CrasherrorApp 捕捉到未處理的異常
API Errorerror後端 API 回傳非預期的錯誤碼（如 500）
Logininfo用戶登入成功 / 失敗（可選）
Performancealert頁面載入超過 X 秒
FCMerrorFCM token 註冊失敗
Debuginfo開發期間需要追蹤的事件

2.2 注意事項

  • 此 API 需要登入（需帶 Authorization header），未登入會回 401
  • message 為空白時不會發送（直接回 200）
  • 訊息會自動附上當前用戶 ID（User#xxx）
  • 支援換行符 \n，可在 message 中帶多行資訊
  • Telegram 訊息使用 HTML 格式，請勿在 message 中使用 HTML 標籤（如 <script>），會導致發送失敗

2.3 頻率建議

  • Telegram Bot API 限制：同一群組每秒最多 20 條訊息
  • 建議 App 端做 節流（throttle）：相同 tag 的 error 在 60 秒內只發一次
  • 不要對每個 API 請求都發 log，僅發送異常和關鍵事件

3. React Native 實作範例

3.1 TelegramLogger 工具

// src/utils/telegramLogger.ts
import { API_BASE_URL } from '@/config';

const THROTTLE_MAP = new Map<string, number>();
const THROTTLE_MS = 60000; // 相同 tag 60 秒內只發一次

export async function sendTelegramLog(
  token: string,
  tag: string,
  message: string,
  level: 'info' | 'error' | 'alert' = 'info',
) {
  if (!message?.trim()) return;

  // 節流：相同 tag+level 60 秒內只發一次
  const throttleKey = `${tag}:${level}`;
  const last = THROTTLE_MAP.get(throttleKey) || 0;
  if (Date.now() - last < THROTTLE_MS) return;
  THROTTLE_MAP.set(throttleKey, Date.now());

  try {
    await fetch(`${API_BASE_URL}/api/v1/telegram/log`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${token}`,
      },
      body: JSON.stringify({ tag, message, level }),
    });
  } catch {
    // 靜默失敗，不影響 App 正常運作
  }
}

// 快捷方法
export const tgInfo  = (token: string, tag: string, msg: string) =>
  sendTelegramLog(token, tag, msg, 'info');
export const tgError = (token: string, tag: string, msg: string) =>
  sendTelegramLog(token, tag, msg, 'error');

3.2 使用範例

// 捕捉全域錯誤
import { tgError } from '@/utils/telegramLogger';
import { ErrorUtils } from 'react-native';
import { Platform } from 'react-native';

ErrorUtils.setGlobalHandler((error, isFatal) => {
  const msg = [
    `${isFatal ? 'FATAL' : 'ERROR'}: ${error.message}`,
    error.stack?.split('\n').slice(0, 5).join('\n'),
    `platform: ${Platform.OS} ${Platform.Version}`,
  ].join('\n');
  tgError(token, 'Crash', msg);
});

// API 呼叫失敗時
import { tgError } from '@/utils/telegramLogger';

async function fetchPosts() {
  try {
    const res = await api.get('/api/v1/posts');
    if (res.code !== 200) throw new Error(`API error: ${res.code} ${res.message}`);
  } catch (e) {
    tgError(token, 'API Error', `GET /posts 失敗: ${e.message}`);
  }
}

// 一般通知
import { tgInfo } from '@/utils/telegramLogger';

// 用戶登入成功
tgInfo(token, 'Login', `Google 登入成功`);

// FCM token 註冊
tgInfo(token, 'FCM', `Token 註冊成功: ${fcmToken.slice(0, 20)}...`);
