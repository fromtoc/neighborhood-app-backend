App 版本更新 — 完整串接指南 GoLocal 後台 + iOS / Android App 串接說明

一、架構總覽

App 啟動 ↓ GET /api/v1/releases/latest?platform=ios ↓ 比對 response.version 與 App 當前版本 ↓ ├─ 版本相同 → 不做事，正常進入 App ├─ 有新版 + isForce=0 → 彈「有新版本」提示（可跳過） └─ 有新版 + isForce=1 → 彈「必須更新」對話框（不可關閉） ↓ 點「立即更新」→ 開啟 App Store / Google Play

二、資料庫結構

表名：app_release

欄位型別說明
idBIGINT PK自增主鍵
versionVARCHAR(20)版本號，如 1.2.0
platformVARCHAR(20)ios / android / all
titleVARCHAR(100)版本標題
contentTEXT更新說明（支援 Markdown）
download_urlVARCHAR(500)App Store / Google Play 連結
is_forceTINYINT(1)0=可選更新，1=強制更新
is_publishedTINYINT(1)0=草稿，1=已發佈
published_atDATETIME發佈時間
created_atDATETIME建立時間
updated_atDATETIME更新時間
deletedTINYINT(1)軟刪除

三、API 端點

公開 API（App 呼叫，無需 Token）

GET   /api/v1/releases/latest?platform={platform} 公開

取得指定平台最新的已發佈版本。

Query 參數：

  • platform — ios / android（預設 all）

回傳範例：

{ "code": 200, "data": { "id": 1, "version": "1.2.0", "platform": "all", "title": "v1.2.0 新功能上線", "content": "1. 新增收藏功能\n2. 修復通知問題", "downloadUrl": "https://apps.apple.com/app/id123456", "isForce": 0, "isPublished": 1, "publishedAt": "2026-03-18T10:00:00" } }

錯誤回傳（尚無發佈版本）：

{ "code": 404, "message": "尚無已發佈版本" }

管理 API（需管理員 Token）

方法路徑說明
GET/api/v1/mgmt/releases版本列表（分頁）
POST/api/v1/mgmt/releases新增版本
PUT/api/v1/mgmt/releases/{id}編輯版本
PUT/api/v1/mgmt/releases/{id}/publish?value=true發佈 / 下架
DEL/api/v1/mgmt/releases/{id}刪除（軟刪除）

四、後台操作流程

1. App 新版上架 App Store / Google Play
等審核通過、正式上架後再操作後台。
2. 登入管理後台 → /admin/releases
使用管理員帳號登入。
3. 點「新增版本」
填寫以下欄位：
• 版本號：與 App 實際版本一致，如 1.2.0
• 平台：ios / android / all
• 標題：如「v1.2.0 新增收藏功能」
• 更新說明：條列式描述更新內容
• 下載連結：App Store 或 Google Play 的頁面網址
• 強制更新：一般選「否」，有安全漏洞時選「是」
4. 確認無誤後點「發佈」
發佈後 App 端即時生效，舊版用戶下次啟動就會看到更新提示。
⚠️ 注意：版本號必須與 App 實際發佈的版本號一致。如果 App 是 1.2.0，後台也要填 1.2.0。App 端會用字串比對來判斷是否需要更新。

5.2 Android（Kotlin）

// 1. 版本比較工具
fun compareVersion(current: String, latest: String): Int {
    val c = current.split(".").map { it.toIntOrNull() ?: 0 }
    val l = latest.split(".").map { it.toIntOrNull() ?: 0 }
    for (i in 0 until maxOf(c.size, l.size)) {
        val cv = c.getOrElse(i) { 0 }
        val lv = l.getOrElse(i) { 0 }
        if (cv != lv) return cv.compareTo(lv)
    }
    return 0
}

// 2. 啟動時呼叫
fun checkForUpdate() {
    viewModelScope.launch {
        try {
            val resp = api.getLatestRelease(platform = "android")
            if (resp.code != 200 || resp.data == null) return@launch

            val latest = resp.data
            val current = BuildConfig.VERSION_NAME
            if (compareVersion(current, latest.version) < 0) {
                if (latest.isForce == 1) {
                    showForceUpdateDialog(latest)
                } else {
                    // 同版本 24 小時內跳過一次的用戶不再提示
                    if (!isUpdateSkipped(latest.version)) {
                        showOptionalUpdateDialog(latest)
                    }
                }
            }
        } catch (e: Exception) {
            // API 失敗時靜默跳過，不影響正常使用
        }
    }
}

// 3. 強制更新對話框
fun showForceUpdateDialog(release: ReleaseResponse) {
    AlertDialog.Builder(context)
        .setTitle("必須更新至 v\${release.version}")
        .setMessage(release.content)
        .setCancelable(false)  // 不可關閉
        .setPositiveButton("立即更新") { _, _ ->
            openUrl(release.downloadUrl)
        }
        .show()
}

// 4. 可選更新對話框
fun showOptionalUpdateDialog(release: ReleaseResponse) {
    AlertDialog.Builder(context)
        .setTitle("有新版本 v\${release.version} 🎉")
        .setMessage(release.content)
        .setPositiveButton("立即更新") { _, _ ->
            openUrl(release.downloadUrl)
        }
        .setNegativeButton("稍後再說") { dialog, _ ->
            markUpdateSkipped(release.version)
            dialog.dismiss()
        }
        .show()
}

// 5. 跳過記錄（SharedPreferences）
fun isUpdateSkipped(version: String): Boolean {
    val prefs = context.getSharedPreferences("update", MODE_PRIVATE)
    val skippedVersion = prefs.getString("skipped_version", null)
    val skippedAt = prefs.getLong("skipped_at", 0)
    val expired = System.currentTimeMillis() - skippedAt > 24 * 60 * 60 * 1000
    return skippedVersion == version && !expired
}

fun markUpdateSkipped(version: String) {
    context.getSharedPreferences("update", MODE_PRIVATE).edit()
        .putString("skipped_version", version)
        .putLong("skipped_at", System.currentTimeMillis())
        .apply()
}

5.3 iOS（Swift）

// 1. 版本比較
func isUpdateAvailable(current: String, latest: String) -> Bool {
    return current.compare(latest, options: .numeric) == .orderedAscending
}

// 2. 啟動時呼叫
func checkForUpdate() async {
    guard let url = URL(string: "\(baseURL)/api/v1/releases/latest?platform=ios") else { return }
    do {
        let (data, _) = try await URLSession.shared.data(from: url)
        let resp = try JSONDecoder().decode(ApiResponse<ReleaseData>.self, from: data)
        guard let release = resp.data else { return }

        let currentVersion = Bundle.main.infoDictionary?["CFBundleShortVersionString"] as? String ?? "0"
        guard isUpdateAvailable(current: currentVersion, latest: release.version) else { return }

        await MainActor.run {
            if release.isForce == 1 {
                showForceUpdateAlert(release)
            } else if !isUpdateSkipped(release.version) {
                showOptionalUpdateAlert(release)
            }
        }
    } catch {
        // 靜默失敗
    }
}

// 3. 強制更新（不可關閉）
func showForceUpdateAlert(_ release: ReleaseData) {
    let alert = UIAlertController(
        title: "必須更新至 v\(release.version)",
        message: release.content,
        preferredStyle: .alert
    )
    alert.addAction(UIAlertAction(title: "立即更新", style: .default) { _ in
        if let url = URL(string: release.downloadUrl ?? "") {
            UIApplication.shared.open(url)
        }
        // 用戶返回 App 時重新顯示
        DispatchQueue.main.asyncAfter(deadline: .now() + 1) {
            self.showForceUpdateAlert(release)
        }
    })
    UIApplication.topViewController()?.present(alert, animated: true)
}

// 4. 可選更新
func showOptionalUpdateAlert(_ release: ReleaseData) {
    let alert = UIAlertController(
        title: "有新版本 v\(release.version) 🎉",
        message: release.content,
        preferredStyle: .alert
    )
    alert.addAction(UIAlertAction(title: "立即更新", style: .default) { _ in
        if let url = URL(string: release.downloadUrl ?? "") {
            UIApplication.shared.open(url)
        }
    })
    alert.addAction(UIAlertAction(title: "稍後再說", style: .cancel) { _ in
        self.markUpdateSkipped(release.version)
    })
    UIApplication.topViewController()?.present(alert, animated: true)
}

// 5. 跳過記錄
func isUpdateSkipped(_ version: String) -> Bool {
    let skipped = UserDefaults.standard.string(forKey: "skipped_version")
    let skippedAt = UserDefaults.standard.double(forKey: "skipped_at")
    let expired = Date().timeIntervalSince1970 - skippedAt > 86400
    return skipped == version && !expired
}

func markUpdateSkipped(_ version: String) {
    UserDefaults.standard.set(version, forKey: "skipped_version")
    UserDefaults.standard.set(Date().timeIntervalSince1970, forKey: "skipped_at")
}

八、注意事項

項目建議
檢查頻率每次冷啟動 + 從背景回前景時（加 30 秒 debounce）
可選更新跳過同版本被跳過後 24 小時內不再提示
強制更新對話框不可關閉、不可返回；用戶從 Store 回來後重新檢查
API 失敗靜默跳過（404 / 網路錯誤），不影響正常使用
版本號格式統一使用 major.minor.patch（如 1.2.0）
先上架再發佈務必等 App Store / Google Play 審核通過後，再到後台發佈版本
platform 欄位iOS / Android 同時發版用 all；若只更新單平台，填對應值
